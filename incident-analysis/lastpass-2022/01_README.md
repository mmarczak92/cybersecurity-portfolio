This repository contains my independent analysis of the 2022 LastPass security incidents.

The analysis is based on the official incident reports published by LastPass and includes:

- Incident overview and timeline
- Threat actor assessment
- Initial access vector analysis
- Attack objectives
- CIA Triad impact assessment
- Cyber Kill Chain mapping
- MITRE ATT&CK mapping *(work in progress)*
- MITRE D3FEND mapping *(work in progress)*
- Security recommendations
